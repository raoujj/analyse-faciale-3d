# Analyse faciale 3D

## Modèle DECA

Le fichier `deca_model.tar` est nécessaire pour exécuter la reconstruction DECA.

Télécharger le modèle ici :

[ Télécharger deca_model.tar ](https://drive.usercontent.google.com/download?id=1rp8kdyLPvErw2dTmqtjISRVvQLj6Yzje&export=download&authuser=0)

Après le téléchargement, placer le fichier sans le décompresser dans :

```text
external/DECA/data/deca_model.tar
```

Vérifier que le fichier existe :

```powershell
Test-Path .\external\DECA\data\deca_model.tar
```

Le résultat doit être :

```text
True
```
